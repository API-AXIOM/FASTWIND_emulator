# Data and checkpoints

The FASTWIND calculations, prepared HDF5 datasets, and trained neural-network
checkpoints are too large to include in this Git repository. They are available
from the repository author upon reasonable request, subject to any FASTWIND or
institutional data-sharing conditions.

## Five-parameter inputs

The default expected layout is:

```text
data/five_parameter/
├── all_parameters.txt                   # used by architecture timing metadata
└── models_LHC/
    └── <model_id>/
        ├── INDAT
        ├── CONVERG
        ├── OUT.HGAMMA_VTV010
        └── OUT.<LINE>_VTV010
```

The training script performs the convergence selection directly from these
model directories. Adopted checkpoints may be placed in:

```text
outputs/five_parameter/emulators_per_line_hg/
```

## Thirteen-parameter inputs

For the compressed-file LHC workflow:

```text
data/thirteen_parameter/
├── grid_large_log_LHC.json
├── grid_quality_large_lhc.json
├── ml13_training_filter_config_linelevel_absflux15_1p5vinf.json
├── ml13_training_filter_config_linelevel_absflux15_1p5vinf_37lines.json
├── ml13_training_filter_config.json
└── all_models_more_info/
    └── <model_id>/
        └── OUT.<LINE>_VTV010.zst
```

For the prepared HDF5 workflow:

```text
data/thirteen_parameter/<dataset_name>/
├── models.h5
├── out_lines.h5
├── manifest.json
└── training_filter_config_linelevel_absflux15_1p5vinf.json
```

The convergence and filtering JSON files are treated as supplied dataset
metadata. They are not regenerated by the consolidated training script.

Training outputs are written below:

```text
outputs/thirteen_parameter/runs/<run_tag>/
```

## FLUXCONT inputs

The default expected layout is:

```text
data/fluxcont/
├── grid_large_log_LHC.json
├── grid_quality_large_lhc.json
└── all_models_more_info/
    └── <model_id>/
        └── FLUXCONT or FLUXCONT.zst
```

The FLUXCONT training script performs the flux conversion, wavelength
selection, target scaling, dataset split, and training after reading these
inputs. Its runs are written to:

```text
outputs/fluxcont_runs/<run_tag>/
```

## Using alternative storage

The data and output trees do not need to be inside the repository. Set:

```bash
export FASTWIND_DATA_ROOT=/large/storage/fastwind_data
export FASTWIND_OUTPUT_ROOT=/large/storage/fastwind_outputs
```

or pass the corresponding path options directly. Command-line options are the
recommended choice for batch and SLURM jobs because they make each submitted
run self-documenting.

## Integrity information

When the datasets and checkpoints are deposited in a public archive, this file
should be updated with:

- the permanent URL and DOI;
- the archive version;
- SHA-256 checksums;
- the precise dataset directory represented by each archive; and
- the checkpoint configuration and training-data version.

Until that archive exists, users should request the files from the author and
record their checksums alongside the generated `run_config.json` and
`training_summary.json` files.
